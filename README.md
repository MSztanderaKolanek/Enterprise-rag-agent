# Enterprise RAG & Knowledge Agent

A modular Retrieval-Augmented Generation (RAG) pipeline built with Python and LangChain for domain-specific document Q&A.

## Key Features
- Document Loading
- Text Splitting (RecursiveCharacterTextSplitter)
- Vector Embeddings
- Similarity Search (`ChromaDB` / `FAISS`)
- LLM Chain integration with custom prompt templates
- Unit testing setup with `pytest`

## Tech Stack
- Python 3.10+
- LangChain 
- ChromaDB
- FAISS
- pytest
